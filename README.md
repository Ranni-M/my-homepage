# 阮耀辉 · 个人主页

AI 应用开发实训（Vibe Coding）· 模块一 · 第 3 次课实践作品。

公开地址：<https://ranni-m.github.io/my-homepage/>

## 是什么

一个用纯 HTML + CSS + 原生 JavaScript 写的多页面个人主页：AI 生成首版结构，再经 5 轮人工迭代形成最终风格，最后部署到 GitHub Pages。

## 页面结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 主页：首屏定位 + 数据条、教育背景、精选项目、技能分组、笔记精选、联系方式、CTA |
| `projects.html` | 作品集：6 个项目的「做了什么 / 用什么方法 / 结果如何」 |
| `notes.html` | 学习笔记：6 篇复盘，从 AI 协作到部署踩坑 |
| `about.html` | 关于我：自我介绍、日常工具链、学习时间线、能力自评 |
| `contact.html` | 联系：联系方式、常见问题、留言表单（mailto 提交，无后端） |
| `style.css` | 全站样式：米黄色（Claude 风格）设计变量 + 响应式 |
| `script.js` | 锚点平滑滚动、导航区块高亮、移动端汉堡菜单、表单校验 |

## 迭代记录

```
迭代1 · 风格    改为米黄色（Claude 风格），统一配色与卡片圆角
迭代2 · 布局    首屏突出姓名、区块留白统一 80px、项目卡片等高
迭代3 · 细节    卡片悬停上浮、导航区块高亮、胶囊标签、页脚署名
迭代4 · 响应式  375px 单列堆叠、汉堡菜单、头像缩小
迭代5 · 内容    单页扩为 5 个页面，补数据条、技能分组、笔记与关于页
```

## 设计说明

- 主背景 `#F0EEE6`（暖米黄），卡片 `#FAF9F5`，正文 `#141413`，主色 `#D97757`（陶土橘），描边 `#E3DED2`。
- 全部颜色走 CSS 变量，改一处即可换肤。
- 无外部依赖：不引入任何 CDN、字体或图片文件，头像用文字 + CSS 圆形实现，加载快也不会出现死链。

## 本地运行

直接双击 `index.html` 即可；或起一个静态服务器：

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```

## 部署

推送到 GitHub 仓库的 `main` 分支，再在 Settings → Pages 里把 Source 设为
`Deploy from a branch`、Branch 选 `main` + `/ (root)`，等待 1~2 分钟即可。
