关于我

数字媒体技术专业大一在读，方向选全栈。喜欢「做出来」的感觉：一个想法从脑子里到浏览器里能打开，中间那段路是我最有耐心的部分。

我这一年在做什么

我是阮耀辉，金陵科技学院数字媒体技术专业 2025 级学生。选这个专业的原因是它同时踩在教学和设计两边：既要写代码，也要处理图像、视频和交互。写页面的时候我会顺手想「这个字距看着舒服吗」，做海报的时候又会想「这块能不能用代码批量生成」。

学技术的方式比较笨：不追求学完再动手，而是想做什么就先动手，缺什么补什么。半年来把前端基础、Git 工作流、Node.js 接口和 Python 小脚本都摸了一遍，最大的收获不是某个语法，而是知道遇到不会的东西时该按什么顺序查。

现在最感兴趣的是「AI 辅助开发流程」本身：怎么把模糊需求拆成 AI 能接住的提示，怎么验收它给的结果，怎么在它写砸的时候快速退回上一步。

学习时间线

  • 2025.09

    入学 · 数字媒体技术

    第一学期接触 HTML 与 CSS，写出第一个静态页面，知道了「盒子模型」不是玄学。

  • 2025.10

    第 1 次课 · 猜数字小游戏

    第一次用 AI 辅助写完整的 JavaScript 程序，学会了让 AI 帮忙列边界用例，也第一次见识到「输入非数字就崩」这种低级但致命的 bug。

  • 2025.11

    第 2 次课 · 记账本 Web App

    开始用 localStorage 存数据，第一次做数据统计；也是在这次完成了第一次代码重构（300 行 → 180 行）。

  • 2025.12 – 2026.02

    自学 Node.js 与 Python 脚本

    写出校园二手信息墙的接口部分；顺手用 Python + Pillow 给社团做了封面批处理脚本，第一次感受到「代码能省下真实时间」。

  • 2026.03

    把项目跑在 Git 上

    养成「每完成一件小事就提交一次」的习惯，学会了看 git log 判断自己这两天到底干了什么。

  • 2026.04

    第 3 次课 · 个人主页上线

    从一句提示词生成首版，5 轮迭代形成自己的风格，多页面结构 + 响应式，最后部署到 GitHub Pages 拿到公开 URL。

  • 接下来

    计划

    补齐 JavaScript 进阶（异步、模块化）与数据库基础，做一个需要真实登录和数据持久化的完整项目；同时把笔记整理成可检索的站点。

能力自评

做得比较顺的

  • 把设计稿或参考站点还原成响应式页面，桌面/移动两端都能验收通过。
  • 用「区域 + 现状 + 期望」的方式跟 AI 沟通，能快速收敛到想要的样式。
  • 主动排查问题：从报错信息、DevTools 到二分法定位，不太容易卡死在一个点上。
  • 把过程写下来——笔记里的踩坑记录基本都是当天写的。

还在补的

  • JavaScript 深层机制：原型链、事件循环这些概念还停留在「会用」的层面。
  • 数据库：只在课程里用过 SQLite，复杂查询和索引还没实战过。
  • 多人协作：目前项目基本是一个人做，Pull Request 流程只跑通过两次。
  • 性能优化：知道要看 DevTools 的 Performance 面板，但看得还不够懂。
