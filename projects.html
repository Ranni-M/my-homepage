作品集

6 个项目，从课程作品到自娱自乐的小工具。每一个都能说明一件事：我从中学到了什么，以及它在什么场景下真的被用上了。

课程与团队项目

校园二手信息墙

2026.03 · 全栈

面向校内同学的信息发布墙：发布、分类筛选、关键字搜索、图片可选上传。用 Node.js + Express 提供接口，前端用原生 JavaScript 渲染列表，数据存 JSON 文件。

  • 做了什么：从接口设计到页面渲染整条链路，独立完成前端与 60% 的后端。
  • 用什么方法：先和同学手画信息结构图，再让 AI 生成接口骨架，自己补参数校验。
  • 结果如何：上线两周累计发布 120 余条信息；一次关键词搜索从 400ms 优化到 60ms（先按分类过滤再模糊匹配）。
  • Node.js
  • Express
  • REST API
  • JSON 存储

记账本 Web App

2025.11 · 前端

第 2 次课课程作品。收支记录 + 分类统计 + 月度汇总，数据存在浏览器 localStorage 里，关掉页面也不丢。

  • 做了什么：记录增删改查、分类占比条、月份切换、空状态提示。
  • 用什么方法：让 AI 把「逐条操作 DOM」重构成「一次性拼装字符串再写入」，并补了输入校验。
  • 结果如何：脚本从约 300 行降到约 180 行；1000 条记录下的渲染耗时下降约 60%。
  • JavaScript
  • localStorage
  • 数据统计
  • 重构

猜数字小游戏

2025.10 · 前端

第 1 次课课程作品。1–100 猜数字，含难度切换（3 个区间）、次数统计、历史记录与「已猜过」提示。

  • 做了什么：完整游戏逻辑 + 交互反馈 + 键盘回车提交。
  • 用什么方法：写完先让 AI 列边界用例（空输入、负数、超范围、重复数字），逐条验证。
  • 结果如何：修掉了「输入非数字页面崩溃」的问题，把提示文案从「输入无效」改成「请输入 1–100 之间的整数」。
  • JavaScript
  • DOM 交互
  • 边界测试

个人主页（本页所在站点）

2026.04 · 全栈

第 3 次课实践作品。用一句提示词生成首版结构，再经 5 轮迭代形成米黄色风格的多页面站点，最后部署到 GitHub Pages。

  • 做了什么：单页 → 5 个页面（主页 / 作品集 / 笔记 / 关于 / 联系）；导航锚点、滚动高亮、悬停动效、移动端汉堡菜单。
  • 用什么方法：每轮只改一类事（风格 / 布局 / 细节 / 响应式 / 内容），改完刷新验收再提交。
  • 结果如何：移动端 375px 无横向滚动；7 次提交记录完整，公开 URL 可直接访问。
  • HTML/CSS
  • JavaScript
  • GitHub Pages
  • 响应式

自学的工具类小项目

短视频封面批处理脚本

2026.02 · Python

帮社团剪视频时写的小工具：批量给封面加统一的标题条、圆角与序号，一次处理整个文件夹。

  • 用什么方法：Python + Pillow，读取文件名当标题，按模板定位文字区域。
  • 结果如何：一次活动 48 张封面从手工 2 小时缩短到 15 秒；中文换行按像素宽度计算，避免标题溢出。
  • Python
  • Pillow
  • 批处理
  • 数字媒体

校园活动海报生成器

2026.01 · Canvas

在浏览器里填活动名称、时间、地点，实时预览海报并导出 PNG，内置 3 套版式。

  • 用什么方法：Canvas API 绘制 + 表单双向绑定，导出用 toDataURL 生成下载链接。
  • 结果如何：把「用修图软件改字」的流程变成 30 秒；版式参数全部抽成配置对象，加新版式不用改绘制逻辑。
  • Canvas
  • HTML/CSS
  • 导出图片

课程作业批改助手

2025.12 · Python + AI

给班里整理作业时写的半自动工具：读入学生提交的压缩包，检查文件命名与必需文件，生成一份核对清单。

  • 用什么方法：Python 解压与遍历 + 规则校验，再用大模型接口对代码做一次「可疑写法」提示。
  • 结果如何：40 份作业的初筛从 40 分钟变成 3 分钟，人工只负责确认与打分。
  • Python
  • 自动化
  • AI 接口

静态笔记站生成脚本

2026.03 · Node.js

把 Markdown 笔记批量转成带目录和样式的 HTML 页面，输出目录可直接丢到 GitHub Pages。

  • 用什么方法：Node.js 读文件 + 极简 Markdown 解析，模板字符串拼页面。
  • 结果如何：现在写笔记只用管 .md 文件；顺手学会了 fs/path 模块和路径拼接的坑（Windows 反斜杠）。
  • Node.js
  • Markdown
  • fs 模块
